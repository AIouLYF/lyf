三、学习目标与达标标准

理论掌握程度

  • 能准确说出Python基本数据类型及适用场景
  • 能画出if/for/while的执行流程图
  • 能解释列表、字典的核心操作
  • 能说明函数参数传递方式和模块导入方法
  • 能描述异常处理机制的作用

上机实操能力

  • 能独立安装Anaconda并配置Jupyter环境
  • 能编写30行以内的完整Python程序并调试通过
  • 能使用列表、字典处理50条以上的模拟业务数据
  • 能读写CSV文件并完成简单的数据统计
  • 能为程序添加基本的异常保护

商务数据分析衔接

  • 理解Python作为数据分析工具链的基础地位
  • 能用Python完成"数据读取-清洗-简单统计-结果输出"的完整流程
  • 能读懂并使用后续课程（pandas、matplotlib）的示例代码框架
