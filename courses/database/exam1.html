单元一考查卷：数据库概述与关系数据库基础
满分：100分时间：60分钟闭卷

一、选择题（每题5分，共25分）

第1题 选择题 (5分)
数据库系统的核心是（ ）
A. 数据库
B. 数据库管理系统
C. 数据模型
D. 软件工具
答案解析
正确答案：B（数据库管理系统DBMS）。DBMS是数据库系统的核心软件，负责管理数据库的数据。
第2题 选择题 (5分)
在关系模型中，一个关系对应（ ）
A. 一个字段
B. 一条记录
C. 一张二维表
D. 一个索引
答案解析
正确答案：C（一张二维表）。在关系模型中，关系就是二维表。
第3题 选择题 (5分)
以下不属于关系完整性约束的是（ ）
A. 实体完整性
B. 参照完整性
C. 数据完整性
D. 用户定义完整性
答案解析
正确答案：C（数据完整性）。三大完整性约束是：实体完整性、参照完整性、用户定义完整性。
第4题 选择题 (5分)
以下不属于数据库管理系统的是（ ）
A. MySQL
B. Oracle
C. Excel
D. SQL Server
答案解析
正确答案：C（Excel）。Excel是电子表格软件，不是DBMS。
第5题 选择题 (5分)
目前主流的数据库数据模型是（ ）
A. 层次模型
B. 网状模型
C. 关系模型
D. 面向对象模型
答案解析
正确答案：C（关系模型）。关系模型以二维表为基础，是目前最广泛使用的数据模型。

二、判断题（每题5分，共25分）

第6题 判断题 (5分)
一个表只能有一个主键，但可以有多个外键。
正确
错误
答案解析
正确答案：正确。一个表只能有一个主键（可以是组合主键），但可以有多个外键分别引用不同表。
第7题 判断题 (5分)
数据库（DB）就是数据库管理系统（DBMS）。
正确
错误
答案解析
正确答案：错误。DB是数据的集合，DBMS是管理DB的软件。DBS = DB + DBMS + 应用程序 + 用户。
第8题 判断题 (5分)
外键的值必须是被引用表主键的有效值或空值。
正确
错误
答案解析
正确答案：正确。这是参照完整性的要求，保证表间数据一致性。
第9题 判断题 (5分)
关系模型中，表的一行称为属性，一列称为元组。
正确
错误
答案解析
正确答案：错误。表的一行称为元组（记录），一列称为属性（字段）。说反了。
第10题 判断题 (5分)
VARCHAR类型比CHAR类型更节省存储空间。
正确
错误
答案解析
正确答案：正确。VARCHAR是变长存储，按实际长度存储；CHAR是定长存储，不足补空格。

三、填空题（每空5分，共20分）

第11题 填空题 (5分)
数据库管理系统英文缩写为________。
答案解析
正确答案：DBMS（Database Management System）。
第12题 填空题 (5分)
关系数据库中，表的一行称为________，一列称为________。（填写第一个空）
答案解析
正确答案：元组（Tuple），也叫记录（Record）。一列称为属性（Attribute），也叫字段（Field）。
第13题 填空题 (5分)
能唯一标识表中每条记录的字段称为________，用于建立表间关联的字段称为________。（填写第一个空）
答案解析
正确答案：第一个空：主键（Primary Key）；第二个空：外键（Foreign Key）。
第14题 填空题 (5分)
三大数据模型分别是层次模型、网状模型和________。
答案解析
正确答案：关系模型。关系模型是目前主流的数据模型。
