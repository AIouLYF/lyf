第4章 物流数据分析

理论4课时 + 上机6课时

4.1 物流成本结构

  • 运输成本（最大头，通常占50%~60%）
  • 仓储成本
  • 包装成本
  • 装卸搬运成本
  • 管理成本

4.2 吨公里成本

吨公里成本 = 运输总成本 / (货物吨数 x 运输公里数)

用来比较不同运输方式的效率。单位是元/(吨*公里)。

4.3 配送时效分析

计算订单从出库到签收的时间，统计平均时效、准时率、超时时长分布。

准时送达率 = 准时送达订单数 / 总配送订单数 x 100%

4.4 物流路径优化（简化版）

给定几个配送点和距离，用"最近邻法"（每次去最近的未访问点）找一条较短的路线。不是最优解，但简单实用。

4.5 物流KPI

  • 准时送达率
  • 破损率
  • 每单配送成本
  • 车辆装载率

4.6 Python示例：计算吨公里成本和平均配送时效

import pandas as pd df = pd.read_csv("物流数据.csv") df["吨公里成本"] = df["运输成本"] / (df["货物重量"] * df["运输距离"]) df["配送时效"] = (pd.to_datetime(df["签收时间"]) - pd.to_datetime(df["出库时间"])).dt.days print("平均吨公里成本:", df["吨公里成本"].mean()) print("平均配送时效(天):", df["配送时效"].mean()) print("准时率:", (df["配送时效"] <= df["承诺时效"]).mean())

1 选择题
吨公里成本的单位是？
A. 元/吨
B. 元/公里
C. 元/(吨*公里)
D. 吨/元
答案解析
正确答案是 C. 元/(吨*公里)。吨公里成本 = 运输总成本 / (货物吨数 x 运输公里数)，反映单位运输工作量的成本水平。
2 选择题
物流成本中占比最大的是？
A. 仓储成本
B. 运输成本
C. 包装成本
D. 管理成本
答案解析
正确答案是 B. 运输成本。运输成本是物流成本中最大的一块，通常占总物流成本的50%~60%。
3 填空题
吨公里成本 = 运输总成本 / (________ x 运输公里数)。
答案解析
正确答案是 货物吨数（或货物重量）。吨公里是运输行业常用的工作量单位，吨公里成本反映单位运输工作量的成本水平，便于横向比较不同运输任务。
4 填空题
配送时效分析中，准时送达率 = ________ / 总配送订单数 x 100%。
答案解析
正确答案是 准时送达订单数。准时送达率 = 准时送达订单数 / 总配送订单数 x 100%，是衡量物流服务质量的核心指标之一。
5 判断题
最近邻法一定能找到全局最优的配送路径。
正确
错误
答案解析
正确答案是 错误。最近邻法是一种贪心算法，每次选择最近的未访问点，简单实用但不保证全局最优。可能因为早期选择导致后续路径较长。
