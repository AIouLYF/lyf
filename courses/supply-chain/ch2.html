第2章 采购数据分析

理论4课时 + 上机4课时

2.1 采购KPI指标

  • 采购成本节约率 = (预算价 - 实际价) / 预算价 x 100%
  • 采购周期 = 下单到入库的天数
  • 供应商准时交货率 = 准时交货次数 / 总交货次数 x 100%

2.2 多供应商报价分析

同一物料多个供应商报价，用Excel列表对比，计算最低价、平均价、价差幅度。注意不能只看单价，还要考虑运费、最小订货量、交货周期等。

2.3 采购成本结构

采购总成本 = 物料成本 + 运输成本 + 关税/税费 + 采购管理费用。总成本最低才是真的好，不能只看单价。

2.4 采购趋势分析

按月汇总采购金额，画折线图看波动，找出旺季和淡季。通过趋势分析可以优化采购计划，降低采购成本。

2.5 采购集中度

采购集中度 = 前N大供应商采购金额 / 总采购金额。过高有风险（供应商依赖），过低管理成本高。

2.6 Python示例：计算采购平均价和最低价

import pandas as pd df = pd.read_excel("采购数据.xlsx") # 按物料分组，计算平均采购价和最低价 summary = df.groupby("物料名称")["单价"].agg(["mean", "min", "max"]) print(summary)

1 选择题
采购成本节约率的计算公式是？
A. (实际价-预算价)/实际价
B. (预算价-实际价)/预算价
C. 实际价/预算价
D. (预算价-实际价)/实际价
答案解析
正确答案是 B。采购成本节约率 = (预算价-实际价)/预算价 x 100%。注意分母是预算价，不是实际价。
2 选择题
以下哪项不属于采购KPI？
A. 采购成本节约率
B. 库存周转率
C. 供应商准时交货率
D. 采购周期
答案解析
正确答案是 B. 库存周转率。库存周转率是库存管理指标，不是采购KPI。采购KPI包括采购成本节约率、供应商准时交货率、采购周期等。
3 选择题
采购集中度是指？
A. 采购金额/销售金额
B. 前N大供应商采购金额/总采购金额
C. 供应商数量/采购品种数
D. 采购成本/总成本
答案解析
正确答案是 B。采购集中度 = 前N大供应商采购金额/总采购金额，反映采购依赖少数供应商的程度。过高有风险，过低管理成本高。
4 判断题
采购时只看单价最低的供应商一定是最优选择。
正确
错误
答案解析
正确答案是 错误。采购决策不能只看单价，还要考虑运费、质量、交货周期、服务等总成本因素。单价最低的供应商总到厂成本不一定最低。
5 判断题
采购成本节约率可能为负数。
正确
错误
答案解析
正确答案是 正确。如果实际采购价高于预算价，节约率为负数，表示超支。例如预算100元，实际花了110元，节约率 = (100-110)/100 = -10%。
